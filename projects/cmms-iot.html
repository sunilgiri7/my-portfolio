CMMS IoT Telemetry Platform & RAG Diagnostics

Real-time industrial telemetry, paired with a retrieval assistant that answers maintenance questions

Tech Stack: MQTT, AWS IoT Core, TimescaleDB, PostgreSQL, Django REST, WebSockets, Pinecone

Focus: Industrial IoT, time-series storage, retrieval-augmented diagnostics

Type: Production platform

Overview

Industrial maintenance teams were making decisions from dashboards that could only show the last few hours of sensor data, while the answers to their actual questions lived in technical manuals nobody had time to read. This platform closes both gaps: a telemetry backend that keeps years of high-resolution sensor history queryable in real time, and a RAG assistant that reads the documentation.

Architecture

100+ sensors→MQTT→AWS IoT Core →TimescaleDB→WebSockets
  • Ingestion — MQTT topics feed AWS IoT Core, which streams device payloads into a TimescaleDB hypertable.
  • Continuous aggregates — pre-rolled hourly and daily views keep long-range queries fast instead of scanning raw points.
  • Live delivery — WebSocket channels push both raw and aggregated windows to dashboards, from the last minute out to five-year intervals.

Diagnostics Assistant

A Pinecone-backed retrieval layer indexes maintenance manuals, fault codes, and service history. Engineers ask a question in plain language and get an answer grounded in the actual documentation, cross-referenced with the asset's own telemetry.

Outcome

45%Lower query latency
40%Fewer manual support tickets
100+Sensors streaming live

The win was not a better model — it was removing the wait. Aggregates and WebSockets made the platform feel instant, and the assistant absorbed the repetitive questions that used to land on the support desk.
