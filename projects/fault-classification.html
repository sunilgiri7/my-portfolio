Multi-Class Fault Classification

Inferring machine operating state from noisy industrial sensor trends

Tech Stack: Python, Scikit-learn, Pandas, NumPy, TimescaleDB

Focus: Anomaly detection, time-series classification, feature engineering

Type: Production ML

Problem

Industrial machinery rarely fails without warning — it drifts. A pump slowly loses pressure head, a motor's vibration signature shifts, a compressor starts cycling differently. Operators could see raw sensor lines, but reading a trend across dozens of channels in real time is not a realistic ask.

The goal was a model that answers a simpler question continuously: what state is this machine in right now?

Approach

Feature engineering did most of the work

Raw sensor streams are noisy and unaligned. Before any model was trained, the signal had to be made learnable — and that is where most of the accuracy came from.

  • Time-domain features — statistical moments, rolling-window means and variances, rate-of-change over multiple horizons.
  • Frequency-domain features — band-energy proxies that separate a healthy vibration signature from a degrading one, without needing a full spectral pipeline on every reading.
  • Multi-class classifier — trained to distinguish operating modes (idle, nominal, loaded, faulted) rather than a single binary healthy/unhealthy flag.
  • Real-time surfacing — mode predictions and confidence indicators feed live dashboards alongside the raw telemetry.

Why multi-class instead of binary

Binary approach Multi-class approach
Flags a fault only once behaviour is already abnormal Identifies the operating mode, so drift is visible before failure
One threshold per sensor, tuned by hand One model across many correlated channels
No guidance on what changed Mode transitions point to which regime the asset moved into

Technology Stack

Python Scikit-learn Pandas NumPy Time-Series Anomaly Detection Feature Engineering

Takeaway

On noisy field data, model choice matters far less than whether the features preserve the physical meaning of the signal. Encoding what a vibration band or a rolling variance actually represents beat every architecture experiment that followed.
